# 项目结论（findings）

把项目自己的实验结论写成 `.md` 放在这个目录，运行 `npm run knowledge:index` 后 Agent 就能检索到并在回答里引用。一个结论一个文件，建议用下面的模板：

```
# 结论标题（一句话说清结论）

## 结论
一两句话。

## 数据与方法
数据来源、时间范围、样本量、使用的工具和参数（算法、速率、探测模块）。

## 结果
关键数字。区分“已验证”和“未验证”。

## 局限
种子偏差、限速丢包、别名前缀是否已过滤、探测视角等。
```

注意：不要写入密钥、内部地址和未公开的漏洞细节。没有验证过的内容要明确标注“未验证”，Agent 会把这里的内容当作资料引用。
